# PromptWars submission checklist

Use this before final submission:

- [ ] Run locally with `npm start` and verify http://localhost:3000 opens.
- [ ] Generate a plan and review budget, timeline, vendor checklist, ideas and task checklist.
- [ ] If claiming live GenAI, configure a valid Gemini key privately and verify the app reports **Gemini AI ready** and the generated plan indicates Gemini AI.
- [ ] Do not publish `.env`, API keys, private access tokens or credentials.
- [ ] Check that the GitHub repository is **Public**.
- [ ] Check that the repository size is below **10 MB**.
- [ ] Push all source files to GitHub and open the public repository URL in a signed-out/incognito browser to test access.
- [ ] Record a short walkthrough using `DEMO_VIDEO_SCRIPT.md`.
- [ ] Upload the demo to YouTube as **Unlisted** or to Drive with **anyone with the link can view**.
- [ ] Test the video URL in a private/incognito browser.
- [ ] Submit the repository URL and video URL on the challenge platform. The challenge allows at most three submissions, so review links before submitting.
